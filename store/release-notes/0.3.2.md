# 0.3.2 release notes

## 한국어 (Play ≤500자 / App Store "What's New")

호환성 업데이트 — 더 많은 게임이 실행되고 저장·화면 문제를 고쳤습니다.
- KTF 게임 다수 추가 실행: 강호동맞고2, 마스터오브소드2, 2006월드올림픽, 루빅스큐브, 리얼싸커2009, 각종 타이쿤류 등 40여 종
- SKT 게임 추가 실행: 디지몬RPG, 어스토니시아, 코인마스터 등. 구매자 전용으로 잠겨 있던 Chaos블레이드·노리맥스영웅전·테일즈판타지·스페셜포스도 실행
- 삼국쟁패2가 실행 직후 꺼지던 문제 수정, 저장 후 종료·이어하기가 제대로 동작
- 화면이 한 프레임에 두 번 그려지거나 투명 처리·잘림이 어긋나던 문제 등 렌더링 다수 개선
- 일부 구형 게임이 비정상 종료되던 것을 안전하게 처리

## English

Compatibility update — more titles run, with save and display fixes.
- Many more KTF titles start (Master of Sword 2, 2006 World Olympics, Rubik's Cube, Real Soccer 2009 and many tycoon games; about forty in all)
- More SKT titles run, including Chaos Blade, Tales Fantasy and Special Force — previously locked to the original buyer
- Samguk Jeongpae 2 no longer quits on launch; save-and-exit and Continue now work
- Many rendering fixes; some older titles that crashed now fail safely
