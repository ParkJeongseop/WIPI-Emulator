# 0.3.1 release notes

## 한국어 (Play ≤500자 / App Store "What's New")

호환성 업데이트 — 새 플랫폼 지원과 저장 관련 수정입니다.
- LGT ez-java 게임 지원 추가: JAD+JAR로 된 게임(디지캐럿RPG, 샤먼슬레이어, 슈퍼액션히어로 등 100여 종)을 실행합니다
- 이노티아 연대기(KTF): 동봉 데이터를 인식하지 못해 다운로드를 요구하던 문제, 두 번째 저장부터 오류가 나던 문제 수정 (제보 감사합니다)
- 저장 후 다시 실행하면 이어하기에서 세이브를 불러옵니다
- SKT 게임: 삼국지연의, 닥터K, 메르헨전기, 엑스피드스노보드 등 12종 추가 실행
- 게임 화면이 한 프레임에 두 번 그려지며 대사가 지워지던 문제 수정

## English

Compatibility update — a new platform and save fixes.
- LGT ez-java titles (JAD+JAR suites such as Di Gi Charat RPG, Shaman Slayer, Super Action Hero; about 100 in all) now run
- Inotia Chronicles (KTF): bundled data was not recognised and a download was demanded; the second save failed (thanks for the report)
- A saved game is listed under Continue after restarting
- SKT titles: twelve more start, among them Romance of the Three Kingdoms, Dr. K, Märchen Chronicle and Xpeed Snowboard
- Screens were painted twice per frame, erasing dialogue in some titles (fixed)
