# 0.3.5 release notes

## 한국어 (Play ≤500자 / App Store "What's New")

속도 업데이트 — 게임을 돌리는 방식을 바꿔 훨씬 가볍게 실행합니다.
- 게임 코드 실행 방식 변경: 게임을 불러올 때 코드를 미리 해석해 두고 실행합니다. 연산이 많은 게임(리듬 게임, RPG 전투 등)은 CPU 사용이 절반 이하로 줄어듭니다
- 화면 그리기 개선: 그림을 픽셀 단위가 아니라 줄 단위로 처리해, 화면을 많이 그리는 게임이 2~3배 가벼워졌습니다
- 게임 200여 종으로 측정한 결과 같은 장면을 그리는 데 드는 CPU가 평균 절반 가까이 줄었습니다. 느리던 게임의 프레임이 오르고 발열과 배터리 소모가 줄어듭니다
- 화면과 동작은 이전 버전과 같습니다. 설정 > 프레임 표시로 FPS와 CPU 부하를 확인할 수 있습니다

## English

Speed update — games run much lighter.
- New way of running game code: it is decoded once when a game loads, not on every step. Titles that compute a lot (rhythm games, RPG battles) use less than half the CPU
- Faster drawing: images are handled a row at a time, so titles that redraw a lot are 2–3× lighter
- Across some 200 games, the same scenes take close to half the CPU on average: more frames in slow titles, less heat and battery use
- Games look and behave as before
