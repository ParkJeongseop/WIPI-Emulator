# 0.3.3 release notes

## 한국어 (Play ≤500자 / App Store "What's New")

성능 업데이트 — 게임 실행에 드는 CPU를 줄였습니다.
- 에뮬레이션 속도 개선: 같은 장면을 그리는 데 드는 CPU가 약 30% 줄어, 느리던 게임의 프레임이 나아집니다
- 게임이 대기하는 동안에는 CPU를 쉬게 해 불필요한 발열과 배터리 소모를 줄였습니다
- 설정에 "프레임 표시" 추가: 화면 왼쪽 위에 FPS와 CPU 부하를 보여 줍니다
- 호환성: SK-VM 3D 게임, MIDP 2.0 이미지 처리, 단일 JAR이 든 zip 열기, WIPI Java 픽셀 처리 수정

## English

Performance update — games need less CPU to run.
- Faster emulation: drawing the same scene takes about 30% less CPU, so slow titles gain frames
- The emulator now rests while a game is waiting, cutting needless heat and battery use
- New "Show frame rate" setting: FPS and CPU load in the top-left corner
- Compatibility: SK-VM 3D titles, MIDP 2.0 image handling, zips holding a single JAR, WIPI Java pixel fixes
