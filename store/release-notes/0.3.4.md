# 0.3.4 release notes

## 한국어 (Play ≤500자 / App Store "What's New")

키패드와 치트 — 보내 주신 요청을 반영했습니다.
- 키패드 배치 선택: 휴대폰 / 게임패드(왼쪽 방향키, 오른쪽 숫자) / 좌우 반전. 게임패드 배치에서는 게임 화면이 더 커집니다
- 키 크기 조절: 작게 / 보통 / 크게
- 게임 속도 조절: 0.5×~3× (소리는 원래 속도로 납니다)
- 치트: 일시정지 화면에서 게임 속 숫자(돈, HP 등)를 찾아 값을 바꾸거나 고정할 수 있습니다. KTF·LGT 게임에서 지원합니다

## English

Keypad and cheats — features you asked for.
- Keypad layouts: phone, gamepad (direction keys left, numbers right) or mirrored. The gamepad layouts leave more room for the game screen
- Key size: small, normal or large
- Game speed: 0.5× to 3× (sound keeps its original speed)
- Cheats: from the pause screen, find a number you see in the game (money, HP…) and rewrite or freeze it. Available for KTF and LGT titles
