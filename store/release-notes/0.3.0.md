# 0.3.0 release notes

## 한국어 (Play ≤500자 / App Store "What's New")

호환성 업데이트 — 에뮬레이터 코어를 최신 upstream(wie v0.1.4)과 동기화하고 게임별 문제를 여러 건 고쳤습니다.
- 테일즈위버 막시민편: 아이템창을 열면 종료되던 문제 수정
- SKT 게임: 투명 스프라이트와 회색조 이미지가 제대로 표시됩니다 (삼국지연의2 맵, 웰루시아, 더팜1)
- SKT 게임: 소프트키·통화·볼륨 키가 게임이 기대하는 코드로 전달됩니다 (노리타이쿤 메뉴, 더팜1 대사 진행 등)
- LGT 게임: 텍스트가 한 줄 위에 그려지던 문제 수정 (이스핀편, 바이오크로니클 등), 당구마스터2010·데몬헌터·리얼사커매니저2009·블레이드마스터4·슈퍼액션히어로3 부팅
- KTF 게임: upstream의 네이티브 호출 수정으로 2006독일축구·부루마불2007 등 진행

## English

Compatibility update — the emulator core is synced with upstream wie v0.1.4 and several per-game issues are fixed.
- TalesWeaver (Maximin): no longer quits when opening the item window
- SKT titles: masked sprites and grayscale images now render correctly (Romance of the Three Kingdoms 2 map, Welusia, The Farm 1)
- SKT titles: soft/call/volume keys are delivered with the codes games expect (menus and dialogues now respond)
- LGT titles: text was drawn one line too high (fixed); five more titles boot (Billiard Master 2010, Demon Hunter, Real Soccer Manager 2009, Blade Master 4, Super Action Hero 3)
- KTF titles: upstream native-call fixes let 2006 Germany Soccer, Blue Marble 2007 and others progress
